## 🚀 دەستپێکردن — Get Started

| ژمارە — Step | ڕێنمایی — Instructions |
|---|---|
| **١ — 1** | **Cloudstream** بکەرەوە → **⚙️ ڕێکخستنەکان** → **ڕیپۆکان**<br/>_Open CloudStream → ⚙️ Settings → Repos_ |
| **٢ — 2** | **ڕیپۆ زیاد بکە** → لینکەکە لە سەرەوە پەیست بکە → پشتڕاستی بکەرەوە<br/>_Add Repo → paste the link above → confirm_ |
| **٣ — 3** | بگەڕێوە بۆ **زیادکراوەکان** → ڕاکێشان بۆ خوارەوە بۆ نوێکردنەوە → **چیا TV** دامەزرێنە<br/>_Go to Extensions → pull to refresh → install CHYA TV_ |
| **٤ — 4** | تەواوە — زیادکراوەکان لە شاشەی سەرەکی و لە گەڕاندا دەردەکەون<br/>_Done — plugins appear on home & search_ |

## ❓ چارەسەری کێشەکان — Troubleshooting

| نیشانە — Sign | چارەسەر — Fix |
|---|---|
| ڕیپۆکە لەدوای زیادکردن دەرناکەوێت<br/>_Repo doesn't show after adding_ | لە **زیادکراوەکان** ڕاکێشان بۆ خوارەوە و لینکەکە دووبارە بنووسەوە<br/>_Pull to refresh in **Extensions** and re-enter the link_ |
| کورتکۆدەکە ناکات<br/>_Short code doesn't work_ | سێرڤەری **DNS** لە ڕێکخستنەکانی Cloudstream بگۆڕە<br/>_Change the **DNS** server in CloudStream settings_ |
| ڤیدیۆکە نایلێت / تۆکەنێک بەسەرچووە<br/>_Video won't play / expired token_ | پەیجەکە نوێ بکەرەوە و هەوڵ بدەرەوە — تۆکەنەکان چەند ساعاتێک دەمێننەوە<br/>_Refresh the page and retry — tokens last a few hours_ |
| وەشانی کۆنە<br/>_Old version_ | **چیا TV** دووبارە دامەزرێنە — هەر نوێکردنەوەیەک هاشێکی نوێی هەیە<br/>_Reinstall **CHYA TV** — every update has a new hash_ |
| ژێرنووس نییە<br/>_No subtitles_ | هەندێک سەرچاوە ژێرنووسی نییە — ئەمە لە سێرڤەرەکەوەیە، کێشەی منداڵباوە نییە<br/>_Some sources have no subtitles — that's server-side, not a bug_ |
