## 🚀 Get Started

| Step | Instructions |
|---|---|
| **1.** | Open **CloudStream** → **⚙️ Settings** → **Repos** |
| **2.** | **Add Repo** → paste the link above → confirm |
| **3.** | Go to **Extensions** → pull to refresh → install **CHYA TV** |
| **4.** | Done — plugins appear on home & search |

### 📺 Short Codes for Android TV

Typing the URL with a remote is painful — try one of these instead:

| Code | |
|:---:|:---:|
| `CHYA` | ☁️ |
| `arb` | 🎬 |
| `343` | 📺 |

> If the code doesn't open, switch the **DNS** in CloudStream settings to another server.

## ❓ Troubleshooting

| Sign | Fix |
|---|---|
| Repo doesn't show after adding | Pull to refresh in **Extensions** and re-enter the link |
| Short code doesn't work | Change the **DNS** server in CloudStream settings |
| Video won't play / expired token | Refresh the page and retry — tokens last a few hours |
| Old version | Reinstall **CHYA TV** — every update has a new hash |
| No subtitles | Some sources have no subtitles — that's server-side, not a bug |
